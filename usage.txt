B站视频下载器 · Windows x64

1. 完整解压 ZIP，双击 B站视频下载器.exe。请把 tools 文件夹和程序放在一起。
2. 从 Chrome 地址栏复制 B 站普通投稿的 BV 或 AV 链接，粘贴后点击「读取视频」。也可以粘贴 b23.tv 分享短链。
3. 选择清晰度和保存目录，点击「下载 MP4」。下载完成后用「打开文件夹」找到视频。

每次下载一条普通投稿或一个分 P。下载器以未登录状态读取画质，网页登录后看到的部分画质可能不在列表里。请保存自己有权下载的视频。

1.0.1 版遇到 B 站网页返回 HTTP 412 时，会自动改用 B 站嵌入播放器入口读取视频。

工具使用随附的 yt-dlp 和 FFmpeg。组件版本、来源和许可在 tools 文件夹内。
